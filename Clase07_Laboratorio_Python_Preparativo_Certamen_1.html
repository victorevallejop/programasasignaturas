p = diamonds['price'].dropna()
n = len(p)
xmin = int(p.min())
xmax = int(p.max())
R = xmax - xmin
k = int(np.ceil(1 + 3.322*np.log10(n)))
A = int(np.ceil(R/k))

edges = np.arange(xmin, xmin + A*(k+1), A)

CONSTRUCCIÓN SECUENCIAL

De precios crudos a una tabla analítica

La tabla se completa por columnas: primero los intervalos; después Python cuenta fi; luego derivamos marcas, proporciones, acumulados y productos.

Regla profesional: ninguna columna acumulada existe antes de tener fi; y ninguna media agrupada existe antes de tener xifi.
Paso 1. Partimos desde el mínimo 326 y sumamos la amplitud 1.089: [326,1415), [1415,2504), …, hasta cubrir el máximo 18.823.
Consulta mínima a Python para completar fi

clase = pd.cut(p, bins=edges, right=False, include_lowest=True)

N2 = n/2

mediana_g = fila_mediana['LI'] + ((N2-F_anterior)/fila_mediana['fi'])*A

idx_modal = tabla['fi'].idxmax()
fila_modal = tabla.loc[idx_modal]
f_ant = tabla.loc[idx_modal-1, 'fi'] if idx_modal > 0 else 0

d1 = fila_modal['fi'] - f_ant

moda_g = fila_modal['LI'] + (d1/(d1+d2))*A
