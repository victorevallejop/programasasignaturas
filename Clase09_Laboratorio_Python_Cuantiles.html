CONCEPTO CENTRAL

Definición de cuantiles

Valores de posición que separan proporciones iguales de observaciones

4
IDEA CENTRAL

Un cuantil es un punto de corte

Los cuantiles se calculan sobre los datos ordenados y permiten dividir la distribución en partes con igual proporción de observaciones. Lo importante es la proporción acumulada, no la longitud física del intervalo.

4 partes → cuartiles 5 partes → quintiles 10 partes → deciles 100 partes → percentiles
CUARTILES
Q₁, Q₂, Q₃

Separan 25%, 50% y 75% de la distribución.

QUINTILES
V₁…V₄

Generan cinco grupos de 20% cada uno.

DECILES
D₁…D₉

Ofrecen un nivel intermedio de detalle, de 10% en 10%.

PERCENTILES
P₁…P₉₉

Entregan el mayor detalle: cortes de 1% en 1%.

Importante: dos partes con igual cantidad de datos pueden tener distinta extensión sobre el eje numérico. Eso ocurre cuando la distribución es desigual.
El diagrama es vectorial y se ve nítido en cualquier resolución. Cada fila muestra la misma idea con distinto nivel de segmentación.

EQUIVALENCIAS

Relaciones entre cuantiles

Distintos nombres pueden representar exactamente el mismo punto de corte

5
MEDIANA
Q₂ = D₅ = P₅₀

Todos nombran el mismo punto de corte: deja 50% de los datos en o por debajo del valor.

CUARTILES ↔ PERCENTILES
Q₁ = P₂₅ · Q₃ = P₇₅

Los cuartiles se pueden leer como percentiles particulares: 25% y 75%.

DECILES ↔ PERCENTILES
Dₖ = P₁₀ₖ

Ejemplos: D₁ = P₁₀, D₄ = P₄₀ y D₉ = P₉₀.

QUINTILES ↔ PERCENTILES
Vₖ = P₂₀ₖ

Ejemplos: V₁ = P₂₀, V₂ = P₄₀, V₃ = P₆₀ y V₄ = P₈₀.

Una interpretación correcta siempre debe incluir variable + porcentaje acumulado + sentido.
Los gráficos son vectoriales para conservar nitidez y permitir mayor espacio visual sin perder calidad.
Observa que la escala siempre va de 0% a 100%. Lo que cambia es cómo decidimos dividirla: en 4, 5, 10 o 100 partes.

CONVENCIÓN OFICIAL DEL CURSO

Así calcularemos los cuantiles en esta asignatura

La regla depende de cómo estén representados los datos; declaramos explícitamente el método para evitar ambigüedad

6
DATOS NO AGRUPADOS · VALORES EXACTOS

Hyndman–Fan Type 2

Nombre computacional: averaged_inverted_cdf. Es el método oficial del curso para listas de observaciones y también para tablas de frecuencias de valores exactos.

r = p\,n Si r no es entero: Q(p)=x(⌈r⌉)
Si r es entero: Q(p)=[x(r)+x(r+1)]/2
Importante: Type 2 es discontinuo. No hace interpolación lineal entre observaciones; solo promedia cuando r cae exactamente en el salto.
DATOS AGRUPADOS EN INTERVALOS

NIST/SEMATECH · Grouped Quantile

Usaremos interpolación lineal intraclase, porque ya no conocemos las observaciones individuales dentro del intervalo.

Q(p)=Lc+[(pN−Fc−1)/fc]hc Lc: límite inferior de la clase · Fc−1: acumulada anterior · fc: frecuencia de la clase · hc: amplitud
Supuesto: la frecuencia se distribuye uniformemente dentro de la clase. Por eso el resultado es una estimación del cuantil original.
Regla de la asignatura: valores exactos → Hyndman–Fan Type 2 · intervalos → interpolación lineal intraclase NIST/SEMATECH.

MÉTODO DEL CURSO · DATOS EN INTERVALOS

Interpolación lineal intraclase

No es Hyndman–Fan Type 2: aquí estimamos la posición dentro de la clase que contiene al cuantil

IntervalofᵢFᵢ

Total: N=47. Para P₅₀ buscamos la posición pN=0,50·47=23,5.
Clase contenedora: 20–30, porque 17 < 23,5 ≤ 35.
CÁLCULO SEGÚN NIST/SEMATECH

Percentil 50 = mediana agrupada

Lc=20, Fc−1=17, fc=18, hc=10.

P₅₀ = 20 + [(23,5−17)/18]·10= 20 + 3,6111 ≈ 23,61

El valor 23,61 no estaba necesariamente observado. Es una estimación por interpolación dentro del intervalo.

Generalización: Qₖ usa p=k/4; Vₖ usa p=k/5; Dₖ usa p=k/10; Pₖ usa p=k/100.
No mezclar: Hyndman–Fan clasifica cuantiles de datos individuales. La fórmula intraclase corresponde al caso en que solo conservamos intervalos y frecuencias.

import numpy as np

def cuantil_agrupado(lim_inf, lim_sup, f, p):
    lim_inf = np.asarray(lim_inf, dtype=float)
    lim_sup = np.asarray(lim_sup, dtype=float)
    f = np.asarray(f, dtype=float)

    if not (0 < p < 1):
        raise ValueError("p debe estar entre 0 y 1")
    if not (len(lim_inf) == len(lim_sup) == len(f)):
        raise ValueError("Los vectores deben tener igual longitud")

    F = np.cumsum(f)
    N = F[-1]
    objetivo = p * N
    c = np.searchsorted(F, objetivo, side="left")

    F_prev = 0 if c == 0 else F[c - 1]
    L = lim_inf[c]
    h = lim_sup[c] - lim_inf[c]

    return L + ((objetivo - F_prev) / f[c]) * h

li = [0, 10, 20, 30, 40]
ls = [10, 20, 30, 40, 50]
f  = [5, 12, 18, 8, 4]

for p in [0.25, 0.50, 0.75, 0.90]:
    print(p, round(cuantil_agrupado(li, ls, f, p), 4))

CONTEXTO · ALTERNATIVAS PARA DATOS EXACTOS

¿Por qué hay distintas fórmulas de cuantiles?

Esta discusión corresponde a datos individuales o valores exactos; para intervalos usamos la fórmula agrupada intraclase

0
FORMA GENERAL · HYNDMAN & FAN (1996)
Q(p) = (1−γ)x(j) + γx(j+1)

Los datos se ordenan como x(1) ≤ … ≤ x(n). Cada definición elige de forma distinta j, γ y, por tanto, qué posición representa mejor la probabilidad acumulada p.

CURSO · TYPE 2

Método discontinuo · promedio solo en el salto

No usa interpolación lineal. Si np es entero, promedia x(np) y x(np+1); si no es entero, toma x(⌈np⌉).

i=np
TYPE 6 · WEIBULL

Posiciones k/(n+1)

Usa interpolación lineal con h=(n+1)p. Es una convención clásica y aparece en software como Minitab/SPSS.

h=(n+1)p
TYPE 7 · DEFAULT COMÚN

Interpolación lineal

Usa h=1+(n−1)p. Es el valor por defecto de R y de numpy.quantile(..., method="linear"); pandas usa interpolación lineal por defecto.

h=1+(n−1)p
TYPE 8 · H&F

Aproximadamente median-unbiased

Hyndman y Fan recomiendan Type 8 como estimador aproximadamente insesgado respecto de la mediana de F(x(k)).

h=(n+⅓)p+⅓
Dato de respaldo: Langford (2006) documentó al menos una docena de formas de calcular cuartiles en cursos introductorios, según el texto o el software utilizado. Por eso la fórmula debe declararse para que el cálculo sea reproducible.

ALTERNATIVAS · DATOS EXACTOS

Tipos 1–3: cuantiles discontinuos

Trabajan directamente con estadísticos de orden y cambian mediante saltos

0
j = ⌊np + m⌋ · g = np + m − j · Q(p)=(1−γ)x(j)+γx(j+1)

Para Types 1 y 2: m=0. Para Type 3: m=−½. Lo que cambia es la regla para γ.

Type 1

m = 0
γ = 0 si g=0; 1 si g>0

Es la inversa de la distribución empírica: selecciona una observación de la muestra.

Type 2 · curso

m = 0
γ = 0.5 si g=0; 1 si g>0

Promedia justo en una discontinuidad. Equivale exactamente a la regla usada en esta asignatura.

Type 3

m = −1/2
γ = 0 si g=0 y j es par; 1 en otro caso

Elige el estadístico de orden par más cercano.

Lectura operacional: Types 1–3 son discontinuos. En particular, Type 2 no interpola linealmente: selecciona la observación superior cuando g>0 y solo promedia x(j) con x(j+1) cuando g=0.
EST-001A · Estadística Descriptiva · UTFSM Viña del MarVíctor Vallejo Palacios0
ALTERNATIVAS · DATOS EXACTOS

Tipos 4–9: cuantiles continuos

Types 4–9 son continuos: usan interpolación lineal entre estadísticos de orden; cambia la posición teórica h=np+m

0
h=np+m · j=⌊h⌋ · γ=h−j · Q(p)=(1−γ)x(j)+γx(j+1)

Las seis definiciones difieren en m, es decir, en cómo ubican cada estadístico de orden sobre la escala acumulada.

Type 4

m = 0
pₖ = k/n

Interpolación lineal de la función de distribución empírica.

Type 5 · Hazen

m = 1/2
pₖ = (k−0.5)/n

Coloca los nudos en el centro de los escalones de la distribución empírica.

Type 6 · Weibull

m = p
pₖ = k/(n+1)

Convención clásica; R documenta su uso en Minitab y SPSS.

Type 7 · default

m = 1−p
pₖ = (k−1)/(n−1)

Default de R y NumPy (linear); es también la convención lineal habitual de pandas.

Type 8

m = (p+1)/3
pₖ=(k−1/3)/(n+1/3)

Recomendado por Hyndman–Fan; aproximadamente median-unbiased.

Type 9

m = p/4 + 3/8
pₖ=(k−3/8)/(n+1/4)

Aproximadamente insesgado para estadísticos de orden de una distribución normal.

def cuantil_curso(datos, k, m):
    """Hyndman–Fan Type 2 para p = k/m, con 1 <= k < m."""
    s = pd.Series(datos).dropna().sort_values().reset_index(drop=True)

    if len(s) == 0:
        raise ValueError("No hay datos válidos para calcular el cuantil.")
    if not (1 <= k < m):
        raise ValueError("Debe cumplirse 1 <= k < m.")

    n = len(s)
    i = (k / m) * n

    # Type 2 es discontinuo: NO interpola linealmente.
    if float(i).is_integer():
        pos = int(i)
        return (s.iloc[pos - 1] + s.iloc[pos]) / 2

    pos = int(np.ceil(i))
    return s.iloc[pos - 1]

horas = [3, 5, 2, 7, 6, 4, 9]
q_manual = [cuantil_curso(horas, k, 4) for k in (1, 2, 3)]
print("Curso:", q_manual)

# Verificación contra NumPy: H&F Type 2
q_hf2 = np.quantile(
    horas, [0.25, 0.50, 0.75], method="averaged_inverted_cdf"
)
print("NumPy Type 2:", q_hf2)
assert np.allclose(q_manual, q_hf2)
print("Verificación correcta")

import urllib.request
import pandas as pd
import numpy as np

url = (
    "https://d37ci6vzurychx.cloudfront.net/trip-data/"
    "yellow_tripdata_2023-01.parquet"
)
archivo = "yellow_tripdata_2023-01.parquet"
urllib.request.urlretrieve(url, archivo)

columnas = ["tpep_pickup_datetime", "tpep_dropoff_datetime"]
df = pd.read_parquet(archivo, columns=columnas, engine="pyarrow")

df["duration"] = (
    df["tpep_dropoff_datetime"] - df["tpep_pickup_datetime"]
).dt.total_seconds() / 60

dur = df["duration"].dropna().to_numpy()
q1, q2, q3 = np.quantile(
    dur, [0.25, 0.50, 0.75],
    method="averaged_inverted_cdf"
)

print("Q1, Q2, Q3 =", q1, q2, q3)
print("IQR =", q3 - q1)
